# Contributing

Teşekkürler! Katkıda bulunmak için aşağıdaki adımları izleyin:

1. Depoyu fork'layın ve yerel olarak klonlayın.
2. Yeni bir branch oluşturun: `git checkout -b feature/özellik-adi`.
3. Anlaşılır commit mesajları kullanın (örn. `feat:`, `fix:`, `docs:`).
4. Kod stilini koruyun ve gerekiyorsa mevcut biçimlendirme araçlarını çalıştırın.
5. Değişiklikleri push'ladıktan sonra bir pull request oluşturun ve değişikliklerin amacını açıklayın.

İletişim: Büyük değişiklikler öncesinde issue açıp tartışma başlatmanız takibi kolaylaştırır.
